# Obtain the original data

Run `python scripts/fetch_data.py` from the project root using the artifact environment described in README. The analysis workbook is `nn2c11968_si_003.xlsx`, from https://doi.org/10.1021/acsnano.2c11968.s003. The script checks repository file size and MD5, records SHA-256, and leaves existing files unchanged after verifying them. The original workbook retains CC BY-NC 4.0 terms; see DATA_LICENSE.md. Raw files are omitted from the release archives.
